# 🌫️ AQI Smart Monitoring System

## 🚀 Overview
Smart air quality monitoring system with real-time data, alerts, and dashboard.

## 🧠 Features
- Real-time AQI monitoring
- Smart alerts system
- SaaS dashboard
- Supabase authentication

## 🛠️ Tech Stack
- React + Tailwind
- Supabase
- ESP32 (IoT device)

## 📂 Structure
- frontend → web app
- device → hardware code
- backend → optional APIs

## ⚡ Setup
```bash
cd frontend
npm install
npm run dev
